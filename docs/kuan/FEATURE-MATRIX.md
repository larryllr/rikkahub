# 宽 API 经典版与原生版功能审计

2.0.5 的正文插图、工具详情和网格兼容更新见 [2.0.5 发布说明](RELEASE-2.0.5.md)。下表保留 2.0.4 的功能迁移基线。

2026-11-24，北京时间。对照线上经典 Android **1.6.10 / 33** 的实际资源包 `34f077ee975433e9a935`、原生 **2.0.4 / 7** 和 RikkaHub **3.3.1**（`2435dbd`）。经典包 SHA-256：`e19569bc9da57a9cb6c0d8a7649ea4338475770b63372b0e1e8ae53e2b7af07e`。经典 Chat 以资源包入口实际导入的 `KuanApiChatView-…-499fa94062f8.js`、对应 `chatClient` 和富内容模块为准。

**本轮对照**

| 功能 | RikkaHub 原有 | 宽 API 2.0.4 及边界 |
| --- | --- | --- |
| 对话内生图、改图 | 有独立媒体创作和原生图片消息，不提供宽 API 分组下的显式生图动作。 | 消息长按菜单可选择该组实际生图模型并填写要求；发送本条消息之前的分支和原附件句柄，不把后续无关轮次带入。GPT 与 Work 各走自己的协议。专业生图仍用于模板、参数及案例。 |
| 经典云历史 | 原生 WebDAV、S3 和 ZIP，不使用经典 Chat 云快照。 | 托管会话菜单可把当前分支合并至经典云快照并读取经典记录。按修订写入，冲突保留副本和附件；不传播删除、不覆盖原生分支树、不自动同步全部聊天。 |
| 网页富回复 | 自带原生工具问答、引用折叠、普通图片预览、Markdown、公式及表格。 | 增加搜索/打开链接阶段、折叠网页图组、原图预览和来源，以及链接型卡片；真实题干与选项沿用 2.0.3。地图、图表和实体仅在有公网链接时作为链接展示，不执行页面脚本或任意 OpenUI 布局。 |
| 经典工程目录 | 原生本地和 SSH 工作区、终端、审批及工具输出。 | `工作区 → 导入经典项目 ZIP` 把文件导入新本地工作区；不接管旧授权、密钥、运行环境、后台任务或编辑历史。 |
| 专业生图续接 | 旧媒体模块有原生前台服务，和宽 API 工作台的任务格式不同。 | 原生前台服务和本机回执独立于 WebView。离开页面可继续，回到工作台恢复任务。应用进程被结束时未完成状态显示中断，不自动重发计费请求；没有声称上游提供进度百分比或可在进程死亡后续领未完成任务。 |
| 直接 Responses | 已识别正式终态事件。 | 托管前台链路收到终态后，正常 EOF 不再要求 `[DONE]`；没有终态仍报断流。响应未成功时不当作已完成。 |

**保留、替换及验证范围**

| 场景 | 原生版现状 | 本轮证据或限制 |
| --- | --- | --- |
| 生图入口与内容 | 保留原按钮和系统快捷方式，以宽 API 专业生图取代独立旧媒体页；有动态模型、案例、模板、参考图、记录、对比和指南。 | 窄屏编辑与图库各自占满可用区；宽屏并排。隔离测试覆盖生成、改图、取消、异常、案例、对比、保存原图到相册和 ZIP。旧独立媒体和视频功能按决定撤下，不列为遗漏。 |
| 消息问答与来源 | 按真实题干分组；选项值来自响应数据。空输入点选提交，草稿或附件存在则只追加。Markdown 参考来源与协议引用可合并折叠。 | 测试覆盖同名变量分题、草稿、附件、链接合并、原文件路径、快照不重复、两种协议、重放和旧归档。不会执行模型输出的脚本；未提供交互数据时不会自造题目或选项。原生 `ask_user` 独立保留。 |
| 聊天与整理 | 原生侧栏、文件夹、标签、收藏、搜索、置顶、分支和导出；输入器与消息使用同一会话数据。 | 不复制经典 WebView 页面或主题，旧主题、主题切换动画及开屏效果是设计替换。 |
| 登录与模型 | 宽 API 登录、注册政策、验证码/二步验证，模型选择器支持分组、GPT/Work、动态模型和推理强度；自定义供应商并存。 | 用隔离目录测试权限、不同分组密钥复用、强度元数据和返回模型。未对线上每个模型、Free/付费档位、Grok、Copilot、国模做真实请求。 |
| 管理与计费 | 余额、用量、管理员 Chat 分组、网页调度和模型/推理强度费率。完整用户、订单和套餐管理仍在官网。 | 隔离测试管理员权限和带修订更新；未改变或验证线上真实扣费、套餐和生产账号状态。 |
| 长对话与附件 | 保留会话压缩、原文件与原生相机/系统选择器；托管路径传原件句柄，并考虑压缩前的文件。 | 实测夹具回放历史附件、ZIP 原附件导入及 `.py` 无改名下载。未压测 200+ 文件、超长回复或跨轮大文件编辑，也未在实体手机弱网/权限受限场景重测。 |
| 服务器续接 | 托管无本机工具的聊天可接单、按游标恢复并在终态确认；BYOK 和依赖设备工具的任务由本机跑。 | 隔离验证重试重置与恢复不重发；不承诺所有上游失败都可无损恢复。含本机工具的任务不伪装成已交服务器。 |
| 工程与终端 | 原生本地工作区、SSH 工作区、文件编辑、运行结果、MCP、技能和审批。 | 回归 ZIP 保留二进制和路径，不运行归档里的内容。未逐一在实体机验收 C、Python、Java、构建 Android APK、SSH 和长时间任务。 |
| 离线与安装 | 原生界面、聊天记录、工作台基本资源在 APK，不依赖在线页面才能打开。更新清单有独立包名、版本码、摘要和签名校验。 | 离线能访问已有本机数据，不能生成或刷新目录，未缓存的图库原图仍可能需要联网。2.x 和经典版独立更新、可并装。原生最低 Android 8.0（API 26），经典包为 Android 6.0（API 23）；Android 6/7 不能安装原生版。 |

本次没有更换后端、账号池、网关、域名或经典 APK。审计流程见 [审计交接](AUDIT-HANDOFF.md)，实现与撤回见 [2.0.4](RELEASE-2.0.4.md)。上游通用搜索富回复单独提交至 [fork 分支](https://github.com/larryllr/rikkahub/tree/codex/web-search-rich-replies)，上游仓库仅允许协作者开 PR。
