# 功能差异与入口

此表以 RikkaHub 3.3.1、经典宽 API Android 1.6.10 和原生宽 API 2.0.0 为比较对象。旧客户端功能描述来自维护仓和版本溯源记录。2.0.0 的发布说明和验收边界见 [RELEASE-2.0](RELEASE-2.0.md)。

| 使用场景 | RikkaHub 3.3.1 | 宽 API 原生候选和旧版差异 |
| --- | --- | --- |
| 首页、输入框、手势、动画 | 原生 Compose、Material 3 Expressive、系统明暗、预测返回 | 沿用原生导航和布局。旧 WebView 主题、主题飘散和启动绘制资源属于旧客户端。 |
| 对话整理 | 侧栏、文件夹、标签、置顶、搜索、批量选择、概览和分支 | 使用同一对话数据源。导入历史进入现有侧栏，可用原生整理操作。 |
| 助手和记忆 | 多助手、提示词、角色卡、模式、知识条目、基于文件的本机记忆 | 原生助手机制保留。宽 API 路由默认省掉额外的自动标题、建议和记忆整理请求。 |
| 自带供应商 | 手工配置 OpenAI、Google、Anthropic，模型列表与能力配置 | 保留同一选择器的自定义供应商，再加入登录即可使用的宽 API 提供方。 |
| 宽 API 认证 | 上游支持自建供应商及特定账号授权 | 设置和模型页有宽 API 账号入口，按服务器政策启用注册及二步验证。每个候选安装绑定一个本机账号资料。 |
| 快捷分组和模型 | 列表可搜索、收藏和切换供方 | 选择器内可切宽 API 分组，目录自动刷新，按权限区分 GPT 与 Work。相同上游模型名可出现在不同组。 |
| 推理强度 | 原生可动效滑块 | 原生滑块使用目录所报的有效档位，选值按会话保存。Auto 使用服务端默认，计划内实际账号的回退行为以服务端记录为准。 |
| 使用情况与管理 | 上游本机统计 | 宽 API 账号页展示服务端余额和用量。管理员可看概况、选择 Chat 分组、管理网页调度与 Chat 费率。完整用户和套餐管理入口在原站。 |
| 续写、流和后台 | 原生消息生命周期与本机流 | 托管文字可由服务器接单，回执存在时显示状态。重开、异常重置和游标回放保留同一消息身份。BYOK 和设备工具使用本机执行链。 |
| 长对话 | 上下文压缩、摘要检查点、消息概览 | 宽 API 托管路径上传实际原件，并考虑压缩前的附件。大规模文件选择性读取、跨轮编辑及最慢上游的长任务仍需复测。 |
| 文件来源 | 系统相机、文件选择、图片、原生文档解析、应用文件库 | 两条模型路径共享原生文件入口。托管路径发送受校验的原件句柄。应用保留可访问的设备原件。 |
| 旧历史和附件迁移 | RikkaHub 原生导入导出 | 同一备份页可导入旧 ZIP 或当前账号云备份。逐会话增量持久化。旧主题、供应商凭据、工程目录和任务回执需各自迁移。 |
| 生成文件与相册 | 原生媒体动作、保存图片及文件管理 | 识别自有下载地址，下载后从本机文件打开或另存。受保护的文件使用当前账号授权。Android 相册动作沿用上游。 |
| 回复表现 | Markdown、代码、表格、数学公式、Mermaid、工具记录 | 原生渲染器负责 Markdown。宽 API GPT 回复解析支持特定声明式题目和选项。点选形成草稿，用户可编辑后发送。 |
| 搜索与引用 | 有独立的搜索供应商、工具结果和引用展示 | 上游独立搜索保留。宽 API 网页工具由服务端决定，旧网页特定引用和全部原生富媒体卡片仍需实测。 |
| 图像和视频 | 原生媒体入口，多类供应商接口、图库和运行记录 | 托管 OpenAI 兼容的生成和改图接到真实分组密钥。旧专业生图的提示词画廊、网页生图专用交互和全部视频供方映射需要后续迁移。 |
| 工程和终端 | PRoot 工作区、SSH、文件编辑、工具卡、MCP 和 Skills | 保留原生工作区、审批和命令结果。工具链按上游运行环境安装流程准备。旧工程项目和任务恢复状态需要另外迁移。 |
| 内置 Web | 本机 Web 服务 | BYOK 路径保留。绑定宽 API 账号后的访问限本机回环，必须设置密码。 |
| 软件更新 | 分发渠道各自检查更新 | 原生 2.0 使用独立公开清单和签名，经典版仍使用原渠道。两个应用可以共存；原生版可覆盖同签名的原生预览。 |

## 视觉评审

以相同字体、窗口和系统明暗对照上游安装包。原生页面优先检查点击密度、手势、键盘进出、滚动位置和模型滑块。新入口优先检查分组切换、账号表单、旧备份导入以及多题跟进时的阅读顺序。窄屏、长题干、大字体和横屏应进入视觉验收记录。界面截图与测试范围从交付记录读取。[审计方法](AUDIT-HANDOFF.md)
