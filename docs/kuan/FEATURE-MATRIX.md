# 宽 API 经典版与原生版功能审计

2026-11-24，北京时间。对照线上经典 Android **1.6.10 / 33** 的实际资源包 `34f077ee975433e9a935`，以及原生 **2.0.3 / 6** 的实现与隔离 Android 测试。经典包 SHA-256：`e19569bc9da57a9cb6c0d8a7649ea4338475770b63372b0e1e8ae53e2b7af07e`。经典 Chat 以资源包入口实际导入的 `KuanApiChatView-…-499fa94062f8.js`、对应 `chatClient` 和富内容模块为准，不以工作树里的旧文件名为准。

**缺失或不等价**

| 优先级 | 经典版行为 | 原生版现状及后续验收 |
| --- | --- | --- |
| 高 | 同一个 Chat 可从本条消息主动发起生图，带着该轮的对话上下文。 | 专业生图已迁移，但聊天消息没有等价的「对这条消息生图」动作，也没有直接把该轮附件、提示词带进工作台的入口。上游随回复送来图片和阶段事件时，原生可显示；这不等于可手动指定。应补同一对话内的主动生图、改图和模型选择，先对比 GPT/Work、免费/付费以及旧附件引用。 |
| 高 | 经典云历史可上传、下载、合并，写入时带修订条件。 | `KuanHistory` 支持旧 ZIP 和经典云历史的单向导入、去重与原附件。原生的 WebDAV/S3 是另外的备份格式；没有向经典云历史双向同步或同步本机编辑、删除与分支。不能直接把经典云快照覆盖成原生数据库。 |
| 中 | 网页搜索除了链接还有浏览阶段、异步图组和部分富内容卡片。 | 2.0.3 恢复声明式问答、来源折叠和网页来源元数据；普通 Markdown、代码、表格、公式仍走原生渲染。尚未迁移 `AsyncImageGroup` 完整图片展示、旧网页的卡片布局和全部 OpenUI 控件。网页搜索阶段事件 `kuan.web_tool.*` 未单独展示，不能说富回复已 1:1 等价。 |
| 中 | 经典工程项目、任务状态和旧应用数据由自己的工作区与备份保存。 | 原生有本地工作区、终端、工具审批和按命令折叠的工具结果；不会迁移经典工程目录、历史审批或未完成任务。工作区首次按原生流程准备运行环境。 |
| 中 | 图片进度和服务器后台生成在经典聊天中可看到相应状态。 | 原生托管聊天收到明确回执才标记服务器接单，消息和阶段恢复各走实际服务协议；专业生图是单独的请求，显示生成阶段和耗时，没有真实百分比和服务端任务恢复。离开工作台或换组不是后台保存生成的保证。 |
| 待核对 | 不同上游对直接流的结尾约定不同。 | 代码审计发现，原生前台 Responses 链路收到完成事件后仍等 `[DONE]`，未收到就关闭的上游可能被报成断流。后台任务回放会补终止标志，不能以它替代前台实测；本轮未改变终止协议。 |

**保留、替换及验证范围**

| 场景 | 原生版现状 | 本轮证据或限制 |
| --- | --- | --- |
| 生图入口与内容 | 保留原按钮和系统快捷方式，以宽 API 专业生图取代独立旧媒体页；有动态模型、案例、模板、参考图、记录、对比和指南。 | 窄屏编辑与图库各自占满可用区；宽屏并排。隔离测试覆盖生成、改图、取消、异常、案例、对比、保存原图到相册和 ZIP。旧独立媒体和视频功能按决定撤下，不列为遗漏。 |
| 消息问答与来源 | 按真实题干分组；选项值来自响应数据。空输入点选提交，草稿或附件存在则只追加。Markdown 参考来源与协议引用可合并折叠。 | 测试覆盖同名变量分题、草稿、附件、链接合并、原文件路径、快照不重复、两种协议、重放和旧归档。不会执行模型输出的脚本；未提供交互数据时不会自造题目或选项。原生 `ask_user` 独立保留。 |
| 聊天与整理 | 原生侧栏、文件夹、标签、收藏、搜索、置顶、分支和导出；输入器与消息使用同一会话数据。 | 不复制经典 WebView 页面或主题，旧主题、主题切换动画及开屏效果是设计替换。 |
| 登录与模型 | 宽 API 登录、注册政策、验证码/二步验证，模型选择器支持分组、GPT/Work、动态模型和推理强度；自定义供应商并存。 | 用隔离目录测试权限、不同分组密钥复用、强度元数据和返回模型。未对线上每个模型、Free/付费档位、Grok、Copilot、国模做真实请求。 |
| 管理与计费 | 余额、用量、管理员 Chat 分组、网页调度和模型/推理强度费率。完整用户、订单和套餐管理仍在官网。 | 隔离测试管理员权限和带修订更新；未改变或验证线上真实扣费、套餐和生产账号状态。 |
| 长对话与附件 | 保留会话压缩、原文件与原生相机/系统选择器；托管路径传原件句柄，并考虑压缩前的文件。 | 实测夹具回放历史附件、ZIP 原附件导入及 `.py` 无改名下载。未压测 200+ 文件、超长回复或跨轮大文件编辑，也未在实体手机弱网/权限受限场景重测。 |
| 服务器续接 | 托管无本机工具的聊天可接单、按游标恢复并在终态确认；BYOK 和依赖设备工具的任务由本机跑。 | 隔离验证重试重置与恢复不重发；不承诺所有上游失败都可无损恢复。含本机工具的任务不伪装成已交服务器。 |
| 工程与终端 | 原生本地工作区、SSH 工作区、文件编辑、运行结果、MCP、技能和审批。 | 本轮未改工程能力；没在实体机逐一验收 C、Python、Java、构建 Android 项目、SSH 管理和长时间任务。 |
| 离线与安装 | 原生界面、聊天记录、工作台基本资源在 APK，不依赖在线页面才能打开。更新清单有独立包名、版本码、摘要和签名校验。 | 离线能访问已有本机数据，不能生成或刷新目录，未缓存的图库原图仍可能需要联网。2.x 和经典版独立更新、可并装。原生最低 Android 8.0（API 26），经典包为 Android 6.0（API 23）；Android 6/7 不能安装原生版。 |

实现入口：`KuanStudioPage`、`KuanProvider`、`KuanPresentation`、`ChatMessage`、`KuanJobs`、`KuanHistory`、`KuanCatalog`、`KuanFiles`、`KuanOperations`、`KuanUpdateGroup`。本次没有更换后端、账号池、网关、域名或经典 APK。审计流程见 [审计交接](AUDIT-HANDOFF.md)，发行和回退见 [2.0.3](RELEASE-2.0.3.md)。
