# 宽 API 2.0.6

原生 Android，版本码 `9`。沿用原包名及签名；经典 1.6.10 独立。

- 富回复标签的识别和转换使用同一份规则。独立的 `badge` 显示为简洁的文字标签；网格、提示框和其他已识别的标签保留正文内容。支持上游转义的标签，流式输出暂不展示未完成的标签。
- 重新打开旧对话时按需修正显示，不迁移数据库，也不重建已有问答、引用或图片。围栏代码块和行内代码保留标签示例，原来的数学公式继续由 Markdown 的公式组件绘制。
- 验收入口：`tools/kuan-presentation/presentation.test.mjs` 和 `KuanReplyLayoutTest.kt`。后者覆盖旧版投影记录、分段到达的标签、公式实际绘制及相邻正文的顺序。

只更新原生渠道和两版下载页。使用 `tools/publish_kuan_android.py withdraw <staging>` 可将下载指针恢复到已验证的 2.0.5，不远程降级、不修改安卓数据、经典版或服务器服务。
