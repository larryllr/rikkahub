# 宽 API 2.0.5

原生 Android，版本码 `8`。沿用原包名及签名；经典 1.6.10 独立。

| 改动 | 审计入口及范围 |
| --- | --- |
| 正文插图 | `KuanPresentation` 与 `tools/kuan-presentation` 按实际网页图片查询锚点生成常规 Markdown，`MessagePartsBlock` 和 `KuanWebIllustration` 在正文同位置显示大图。多图可横滑，保留图源和原图预览；没有可显示图片时不生成占位正文。2.0.4 若已丢失锚点，放到正文开头附近的单个图组，不猜对应段落。 |
| 紧凑回复过程 | `ChatReplyActivity` 在每条回复集中显示一行图标。搜索、思考和其他工具或来源的详情只在点选后打开；有待审批或问答的工具时，图标提示，详情优先列出待处理项。图表、附件、正式问答和正文仍是内容，不当作过程抹掉。 |
| 声明式网格 | `KuanPresentation` 检测 `grid` 与 `grid-item`，包括旧记录与 HTML 转义版本。兼容解析以原顺序输出各项内容和分隔，不执行代码、不复制任意样式；代码块、行内示例和普通文本保持。 |

回退使用 `tools/publish_kuan_android.py withdraw <staging>` 将原生下载指针恢复到 2.0.4；不远程降级、不触碰用户数据、经典版或服务器进程。上游通用富回复分支与经典版的发布状态不受本次影响。
