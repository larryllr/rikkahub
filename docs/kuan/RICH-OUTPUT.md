# 富输出协议与验收

基线：宽 API 原生 Android 2.0.6 / code 9，commit `c920a4b`。本轮使用用户提供的《内联标记与富输出全集》及本地格式样本。网页生成内容不作为代码执行，也不影响 Sub2API、经典 Chat、启动器、账号调度或网络配置。

| 格式族 | 接入行为 |
| --- | --- |
| `i` / `cite` / `filecite` / `[n]` / `sources_footnote` | 按明确引用 ID 或编号接入上角标和折叠来源。文件只使用受管下载地址，禁止直连私有资产指针。 |
| `memcite` | 消除原始标记；不显示或采集未公开的记忆或指令。 |
| `DILn` / `genui` / `client_defined_widget` / `presentation.dil.v1` | 同一消息内按明确槽位、组件 ID 关联。旧版无槽位的图片标签继续兼容唯一的旧查询映射，不用这一映射推断 DIL。 |
| 插图组、搜索图片、异步图片、生图状态 | 正文内展示多图浏览、来源和加载状态。独立生图的裸 Base64 和 `data:image` 为图像字节；`file-service://`、`sediment://` 只由服务端的现有授权下载链解析。 |
| `visualize` / `charts_widget_v2` / 表格原语 | 真实线图、柱图、散点图，或可横滑的表格；不造数据。 |
| `ask_user_input_v2` / `imagegen_ask_user_input_preview` | 显示实际问题及协议提供的选项。只有用户点选后发送明确的后续消息。 |
| 地图、商品、网页组、行情、赛事、文件、媒体、摘要 | 展示已收到的标题、简介、表格、图片或可信链接。地图和商品控件不执行上游的网页脚本。 |
| 工具、活动、隐藏内容、未知组件 | 公开的进度/结束状态可以展示；私有推理、控制器、内部 patch 不进入正文。无法安全执行的交互、缺少数据和加载中分别显示。未知标记的诊断只包含种类，不保存载荷。 |
| 其他布局原语 | 识别用户清单的 50 个原语名称，保留可读内容、布局语义、数学和代码，不将所有原语都宣称为原生交互。例如网页身份验证、宿主弹窗、MCP App 交互没有对应执行权限。 |

非 PUA 的时间行和字段分隔符仅在结构或关联来源可验证时转换。普通文本里的多个空格、`||||` 和 `::::` 不做全局替换。未闭合的协议包不能越过下一段、下个包或代码片段。

## 传输

外置适配器在原有 `kuan_native_presentation` 版本 1 里加入可选 `revision`、`anchors`、`references` 和组件类型数据。修订号按同一消息递增，每一帧是完整快照，不按组件数组顺序定位。Android 可继续接收老快照，不更改 Completions 的结束标记；Responses 的原生生图事件和托管生图结果共同走图像字节验证。后台领取复用同一个解码器。投影后的组件与位置随原有消息序列化保存。

## 回放

- JS：`npm --prefix tools/kuan-presentation test`，然后 `npm --prefix tools/kuan-presentation run build`。
- Android：`KuanRichReplyTest` 覆盖分片、迟到、重复、不同消息 ID、重开历史、实际显示与按钮点击。与 `KuanNativeContractTest`、`KuanFollowUpsTest`、`KuanReplyLayoutTest`、`KuanStudioTest` 一同运行。
- 外置适配器：`go test ./...`，新增协议夹具在 `app/service/web_rich_output_test.go`。只有在运行基线的源文件及构建可追溯、候选和旧客户端兼容验收通过后才切换外置服务。
